# Administration

Everyone but teachers — management, officers and support staff — in one person source (M-13,
DB-04 §4 v1.2, SRS People FR-ADMN-01..09). Offices, committees, admission contacts and other
places add members through the Assignment engine, so a person's phone number is written once
and shows everywhere (AC-ADMN-01).

| | |
|---|---|
| Slug | `administration` |
| Tables | `administration_categories`, `administration_members` |
| Optional | `office` (primary office; Office users see their office's members) |
| Person source | `administration.member` (`MemberPresenter`: hidden contacts stay hidden on every place) |
| Permissions | Generated by Shield from the resources (`*:Member`, `*:AdministrationCategory`); custom: none |
| Settings | Settings › Administration: profile pages on / off, text above the directory; Appearance › Layouts `administration.directory` = grid / list / table |
| Legacy | `php artisan legacy:migrate --step=S11` (after S08 and S10: turns their admin manual persons into members) |

Admin: People › Administration (Import / Export with the same columns: Employee ID, Name,
Designation, Category, Office, Email, Phone, Extension, Active) and People › Staff categories
(the ladder from the top, drag to reorder; group management / officer / support; "in the
directory" — support staff are not, by default).

Rules: the directory, search and sitemap show active members of active public categories; any
active member shows where they are assigned (BRL-ADMN-03); switching a member off hides them
everywhere (FR-ADMN-09); an employee ID is one person's (BRL-ADMN-01).

Website:

| Address | What |
|---|---|
| `/administration` | grouped by category in ladder order; `?group=`, `?category={id}`, `?office={id}`, `?q=` (name, designation), `?view=grid\|list\|table` |
| `/administration/{slug}` | profile: photo, designation, office, public contacts, biography, current public roles (off in Settings → 404) |
