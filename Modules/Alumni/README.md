# Alumni

Graduates — where they studied, what they do now, their stories — and "Pride Alumni" (M-17,
DB-04 §8 v1.5, SRS People FR-ALUM-01..09). A person source: committees, events and other places
can pick alumni.

| | |
|---|---|
| Slug | `alumni` |
| Table | `alumni_alumni` (model `Alumnus`) |
| Optional | `department`, `program` (a program fills the department); scope: Department / Program users manage their own |
| Contacts | email, phone, office address hidden on the website unless switched on (FR-ALUM-06) — on every place, through `AlumnusPresenter` |
| Permissions | Generated by Shield from the resource (`*:Alumnus`); approving = switching on (Update); custom: none |
| Settings | Appearance › Layouts `alumni.directory` = grid / cards / list |
| Legacy | `php artisan legacy:migrate --step=S11A` (after S04) |

Admin: People › Alumni — Import / Export with the same columns (Student ID, Name, Department,
Program, Batch, Passing year, Designation, Organization, Job type, Email, Phone, Pride, Active),
the filter **New submissions** (visitors' entries, still off) with **Approve**, and a menu badge
counting them.

Website:

| Address | What |
|---|---|
| `/alumni` | Pride first; `?department=`, `?program=`, `?batch=`, `?year=`, `?job=job\|business\|higher_study\|other`, `?q=` (name, designation, organization), `?view=`; 24 a page |
| `/{department}/alumni`, `/{program}/alumni` | that department's / program's own (FR-ALUM-05) |
| `/alumni/{slug}` | photo, what they do, where they studied, public contacts, social links, video (YouTube / Drive), story |
| `/alumni/submit` | Livewire form `alumni.submit` — saved switched off, `submission_source = public_form` (FR-ALUM-07); 3 a minute and a trap field |

Homepage section `alumni.pride` "Our Pride Alumni" (settings `count`, `display` slider / grid).
