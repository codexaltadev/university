# News

News of the university and its entities (M-18, DB-05 §3 v1.2, SRS Content v0.2 FR-NEWS-01..06).

| | |
|---|---|
| Slug | `news` |
| Table | `news_posts` (model `Post`, attachable) |
| Where | "Show in" entities (`core_relations`); the main site only by users with `PublishMain:Post` (Admin, Q-26 — AC-NEWS-03); an entity's list also shows the posts of the entities below it |
| Featured | the place's highlight (`HighlightMain:Post` on the main site), with an end date (AC-NEWS-04) |
| Scheduling | `active_at` (kernel `HasActiveAt`): empty = now, future = hidden until then (AC-NEWS-02); no `published_at` |
| Vocabularies | `news.category` (hierarchical, seeded once), shared tags |
| Permissions | Generated by Shield (`*:Post`) plus PublishMain / HighlightMain (attachable) |
| Settings | Settings › News: per page, show author; Appearance › Layouts `news.listing` (grid / list / cards / magazine), `news.detail` (standard / full width) |
| Legacy | `php artisan legacy:migrate --step=S16N` (DIU's one blog post and its categories; news starts afresh — Q-21) |

Admin: Content › News — texts per language, picture, gallery, video link, author (a user or
words), Publishing (active, show from), web address, Show in, Highlight, category / tags, SEO.

Website:

| Address | What |
|---|---|
| `/news`, `/{entity}/news` | this place's posts, newest first; `?category=`, `?tag=`, `?year=` & `?month=` (archive, FR-NEWS-05), `?q=`, `?view=` |
| `/news/{slug}`, `/{entity}/news/{slug}` | only where the post is shown (404 elsewhere): text, video, gallery, tags, more news of the place; counts a view |

Homepage sections (FR-NEWS-04): `news.latest` (builder source modes), `news.featured`
(highlighted, slider / grid), `news.by-category` (chosen categories). Page block "News"
(main-site posts), metric `news.count`, Content Update Reminder source.
