# Committee

Committees and their members (M-16, DB-04 §7 v1.4, SRS People FR-COM-01..07): the Board of
Trustees, Syndicate, Academic Council … on the main site, and an entity's own committees
(a Lab's, a Department's) on its microsite.

| | |
|---|---|
| Slug | `committee` |
| Table | `committee_committees` (assignable, attachable) |
| Members | `core_assignments` in roles `chairperson`, `convener`, `member`, `member_secretary` (catalog order), with an own title and a note per language ("Nominated by UGC") — kernel `PeopleManager::make(withNote: true)` |
| Where | "Show in" (`core_relations`): entities and the main-site switch; entity users manage their entities' committees |
| Vocabulary | `committee.category` (Statutory Bodies, Academic, Administrative — seeded once) |
| Permissions | Generated by Shield from the resource (`*:Committee`), plus PublishMain / HighlightMain (attachable); custom: none |
| Settings | Appearance › Layouts `committee.listing` = table / cards / list |
| Legacy | `php artisan legacy:migrate --step=S13` (after S11): `committee_categories` → committees, `committees` → members |

Terms (FR-COM-05): a committee whose `term_ends_on` has passed is a previous term — not listed,
still reachable, linked from the next term. **Copy to new term** (`Committee::copyToNewTerm()`)
makes the next committee with today's members in the same places and ends this one the day
before.

Website:

| Address | What |
|---|---|
| `/committees`, `/{entity}/committees` | running committees shown in this place, by category; `?category={slug}`, `?view=table\|cards\|list` |
| `/committees/{slug}`, `/{entity}/committees/{slug}` | description, term, members (role, note, contact), formation order PDF, previous terms; 404 where it is not shown (AC-COM-02) |
