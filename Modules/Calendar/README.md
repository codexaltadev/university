# Calendar

Academic calendars (M-11, DB-03 §12 v1.6, SRS Academic v0.4 FR-CAL-01..09): one calendar per
session for some faculties (none = every faculty), its dates as a day, a range, or words only
("1st week of March"), with a type (colour) and an audience (Undergraduate / Graduate).

| | |
|---|---|
| Slug | `calendar` |
| Tables | `calendar_calendars`, `calendar_events` |
| Optional | `faculty` (which faculties a calendar is for — `core_relations`), `program` (program page tab) |
| Vocabularies | `calendar.event-type` (single, colour), `calendar.audience` (several) — seeded once |
| Permissions | Generated by Shield from the resource (`*:Calendar`); dates go with their calendar; custom: none |
| Settings | none; Appearance › Layouts `calendar.show` = table / month / timeline |
| Legacy | `php artisan legacy:migrate --step=S09` (after S04) |

Admin: Academic › Academic Calendar — the calendar form, its dates below (drag to order,
Import from Excel / CSV: Title, Start, End, Date, Type, Audience).

Website:

| Address | What |
|---|---|
| `/academic-calendar` | running calendar(s) first, then the others; `?year=`, `?session=`, `?faculty={slug}`, `?audience={slug}` |
| `/academic-calendar/{slug}` | one calendar; `?view=table\|month\|timeline`, `?audience=`; counts a view (P-17) |
| `/academic-calendar/{slug}.ics` | dated dates as all-day events (FR-CAL-06) |
| `/{microsite}/academic-calendar` | calendars of the entity's faculty (Faculty, Department, Program microsites) |

Also: homepage section and page block "Upcoming Academic Dates" (`calendar.upcoming`,
`calendar-upcoming`), Program page tab "Academic Calendar", search, sitemap, menu item type,
Menus › Module page.

## Views

| View | Variables |
|---|---|
| `calendar::index` | `$current` (list of `['calendar', 'events']`), `$others`, `$years`, `$sessions`, `$faculties`, `$audiences`, `$audience`, `$faculty`, `$filtered`, `$base` |
| `calendar::show` | `$calendar`, `$events`, `$view`, `$months` (`MonthGrid::build`), `$audiences`, `$audience`, `$hardCopy` |
| `calendar::partials.table` / `timeline` | `$events` |
| `calendar::partials.month` | `$months`, `$events` |
| `calendar::partials.upcoming` | `$events` (with `calendar`, `type`) |
| `calendar::sections.upcoming` | `$items`, `$section`, `$settings` |
| `calendar::blocks.upcoming` | `$data` (`count`, `audience`), `$locale` |
| `calendar::tabs.program` | `$entity`, `$calendar`, `$events` |

`CalendarEvent::when()` gives the date text ("22 – 28 February 2026 · Week 1"), `color()` the
type colour (plain `#hex` only) for style attributes.
