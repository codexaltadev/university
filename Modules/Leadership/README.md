# Leadership

The university's leadership and authorities with their messages (M-15, DB-04 §6 v1.3, SRS
People FR-LEAD-01..07): positions in groups, the people who hold them — from any directory
(Administration, later Faculty Members) or manual (a Trustee in no directory) — and each
term's message and biography.

| | |
|---|---|
| Slug | `leadership` |
| Tables | `leadership_positions` (assignable), `leadership_terms` |
| Who and when | `core_assignments` (role `holder` for one-holder posts, `member` for boards); the term keeps the message and biography |
| Vocabulary | `leadership.group` (Board of Trustees, Executive, Academic Leadership — seeded once) |
| Permissions | Generated by Shield from the resource (`*:Position`); terms go with their position; custom: none |
| Settings | Appearance › Layouts `leadership.listing` = grid / cards / list |

Admin: People › Leadership — the positions in order (drag), and on each position its holders:
**Appoint** (person, dates, public, message, biography). For a one-holder post the form offers
to end the current holder's term the day before the new one starts (FR-LEAD-07, AC-LEAD-01).
Code: `Modules\Leadership\Support\Appointments::appoint()` / `update()`.

Website:

| Address | What |
|---|---|
| `/leadership` | today's holders by group (vocabulary order), positions in order; `?view=grid\|cards\|list` |
| `/leadership/former` | past holders by position, latest first ("Former Vice Chancellors") |
| `/leadership/{slug}` | photo, position, tenure, message, biography, link to the directory profile |

Homepage section `leadership.message` (FR-LEAD-06): settings `position_id`, `words`; shows the
current holder's message, so a new VC's message appears as soon as they are appointed.
